# backend/requirements-clone.txt
# ─────────────────────────────────────────────────────────────────────────────
# Voice cloning dependencies — install AFTER requirements.txt.
# These are intentionally separated so Standard TTS users do not need PyTorch.
#
# Usage:
#   pip install -r requirements.txt          # Standard TTS only
#   pip install -r requirements-clone.txt    # Add real voice cloning
#   python -m unidic download                # MeloTTS language data
#
# Then set environment variables before starting the backend:
#   OPENVOICE_ENABLED=true
#   OPENVOICE_CHECKPOINT_DIR=~/.cache/openvoice/v2
#   OPENVOICE_DEVICE=cpu   (or cuda)
#
# Checkpoints (~300 MB) must be downloaded separately.
# See docs/VOICE_CLONING_READINESS.md — Step 3.
# ─────────────────────────────────────────────────────────────────────────────
