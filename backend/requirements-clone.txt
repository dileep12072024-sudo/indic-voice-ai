# backend/requirements-clone.txt
# ─────────────────────────────────────────────────────────────────────────────
# Voice cloning dependencies — install AFTER requirements.txt.
#
# ╔══════════════════════════════════════════════════════════════════════════╗
# ║  ⚠  PYTHON VERSION REQUIREMENT — READ BEFORE INSTALLING  ⚠             ║
# ║                                                                          ║
# ║  Voice cloning (OpenVoice v2) requires Python 3.10 or 3.11.             ║
# ║  Python 3.12, 3.13, and 3.14 are NOT compatible.                        ║
# ║                                                                          ║
# ║  Root cause: OpenVoice's own setup.py pins:                             ║
# ║    numpy==1.22.0          → no cp312+ wheel on PyPI                     ║
# ║    faster-whisper==0.9.0  → ctranslate2<3.17, no cp312+ wheel           ║
# ║    librosa==0.9.1         → needs numba; numba has no cp312+ wheel      ║
# ║    whisper-timestamped==1.14.2 → numba transitive dep                   ║
# ║  These are upstream pins we cannot override without forking OpenVoice.  ║
# ║                                                                          ║
# ║  Standard TTS (Edge-TTS, no cloning) works on Python 3.9–3.14.         ║
# ║  For cloning you must use a Python 3.10 or 3.11 virtual environment.    ║
# ║                                                                          ║
# ║  Windows quick-start (Python 3.10 alongside your existing install):     ║
# ║    See docs/PYTHON_COMPATIBILITY.md for full step-by-step guide.        ║
# ║                                                                          ║
# ║  One-liner to create the correct venv on Windows:                       ║
# ║    py -3.10 -m venv .venv-clone                                         ║
# ║    .venv-clone\Scripts\Activate.ps1                                     ║
# ║    pip install -r requirements.txt                                       ║
# ║    pip install -r requirements-clone.txt                                ║
# ╚══════════════════════════════════════════════════════════════════════════╝
#
# Usage:
#   pip install -r requirements.txt
#   pip install -r requirements-clone.txt      ← inside a Python 3.10/3.11 venv
#   python -m unidic download
#
# Environment variables:
#   OPENVOICE_ENABLED=true
#   OPENVOICE_CHECKPOINT_DIR=~/.cache/openvoice/v2
#   OPENVOICE_DEVICE=cpu          (or cuda)
#   OPENVOICE_AUTO_DOWNLOAD=true  (auto-fetch checkpoints from HuggingFace)
# ─────────────────────────────────────────────────────────────────────────────

# ── PyTorch ──────────────────────────────────────────────────────────────────
# torch>=2.9.0 added Python 3.14 support, but OpenVoice's dep chain (numpy==1.22.0,
# faster-whisper==0.9.0, librosa==0.9.1) limits you to Python 3.10/3.11 regardless.
# We unpin the torch version so pip picks the correct wheel for your Python version.
#
# CPU wheels are served from the PyTorch index — add this flag to your pip call:
#   pip install -r requirements-clone.txt \
#       --extra-index-url https://download.pytorch.org/whl/cpu
#
# Or install torch/torchaudio manually first:
#   pip install torch torchaudio --extra-index-url https://download.pytorch.org/whl/cpu
#
# CUDA 11.8:  --extra-index-url https://download.pytorch.org/whl/cu118
# CUDA 12.1:  --extra-index-url https://download.pytorch.org/whl/cu121
# CUDA 12.4:  --extra-index-url https://download.pytorch.org/whl/cu124
torch>=2.0.0,<3.0.0
torchaudio>=2.0.0,<3.0.0
